OPC 路径：做"MemGraph"——面向独立开发者的 Agent 代码知识图谱即服务平台。核心理念：不是帮你写代码——是帮你的 AI Agent 记住你的代码。让每个 AI Agent 在开始工作前就已经"理解"了你的整个代码库。三个产品层：① 一键代码索引与知识图谱托管（核心产品。用户连接 GitHub/GitLab 仓库→MemGraph 自动完成三步：第一步——代码索引（基于 codebase-memory-mcp 引擎，毫秒级处理，支持 158 种语言，自动识别语言、构建 AST、提取符号关系、函数调用图、类型依赖、模块导入/导出关系）；第二步——知识图谱构建（将索引结果转化为结构化知识图谱——节点=函数/类/模块/接口/类型，边=调用/继承/实现/导入/依赖关系，属性=签名/文档注释/复杂度/最后修改时间/修改人）；第三步——Agent 接入（提供标准 MCP 接口→Claude Code/Codex/Cursor/Copilot/Gemini CLI 等 20+ Agent 直接查询。Agent 可以问："这个项目中用户认证流程涉及哪些文件和函数？""show_balance 函数被哪些模块调用？""最近 30 天修改最多的 5 个文件是什么？"——全部亚毫秒级响应，不消耗用户的 LLM Token）。定价策略：Free——1 个仓库+每月 1000 次查询+7 天数据保留，适合个人项目试用。Maker——¥19/月，3 个仓库+每月 10,000 次查询+30 天数据保留+自动更新（每次 push 自动重建索引）。Pro——¥49/月，10 个仓库+无限查询+90 天数据保留+团队共享知识图谱+变更影响分析（"修改这个函数会影响哪些模块？"）。对比传统方式：一个中型 React 项目约 500 个文件，如果 Agent 每次对话都要读 200 个文件来理解上下文——按 Claude Opus 4.8 的 Token 定价，单次对话上下文建立成本约 $2-5。一个月 100 次对话=$200-500 的纯上下文成本。MemGraph 的 Maker 套餐 ¥19/月——Token 节省 99%——一个月省 $198-495。这不是一个"nice to have"——这是一个 ROI 极其明显的工具。② 代码变更记忆与项目上下文持久化（增值产品。MemGraph 不只是静态索引——它记录代码库的"记忆"。功能一：决策记录自动关联——当 Agent 修改了某个文件，MemGraph 在知识图谱中标记"Agent 于 X 日修改了 Y 文件的 Z 函数，修改原因：修复了 #142 issue"。下次任何 Agent 查询 Z 函数时，这条决策记录自动出现在上下文中。功能二：项目上下文模板——OPC 创始人可以为每个项目设置"项目记忆"（技术栈/架构决策/代码规范/已知坑点/未完成事项），所有 Agent 在开始工作前自动加载这段记忆。功能三：跨项目模式识别——"你在 3 个项目中都使用了类似的认证实现——这是你的'认证模式'。当你在第 4 个项目中需要实现认证时，Agent 可以直接参考这个模式。"定价：Maker 套餐包含基础决策记录+项目上下文模板，Pro 套餐包含跨项目模式识别+团队共享；③ 知识图谱可视化与分析（数据产品。MemGraph 不只是给 Agent 用的——也给开发者本人用。功能一：代码库 3D 图谱——可视化整个代码库的模块依赖关系，一眼看出"循环依赖""过度耦合的模块""从未被调用的死代码"。功能二：热点分析——"过去 30 天修改最频繁的 10 个文件"——这些文件通常是 Bug 高发区或架构瓶颈。功能三：Bus Factor 分析——"如果你明天消失了——接手你的代码库的人会卡在哪些模块上？"——标记"只有你一个人碰过的文件"和"没有任何文档或注释的关键函数"。这个功能对 OPC 创始人尤其重要——一人公司最怕的就是"这个项目只有我能维护"。定价：Maker 套餐包含基础图谱+热点分析，Pro 套餐包含 3D 图谱+Bus Factor 分析。冷启动策略：三重并行。渠道 A：开源 MemGraph CLI——基于 codebase-memory-mcp 封装一个更友好的 CLI 工具（自动检测项目语言、一键索引、本地运行、Agent 协议兼容）。GitHub 开源 MIT 协议。口号："Give your AI agent a memory of your codebase. Skill→记录兼容性→标注"完全兼容/部分兼容/不兼容/未测试"。维度五：可维护性评分。Skill 的最后更新时间、Issue 响应速度、文档完整度、社区活跃度（Star 数/Fork 数/Contributor 数）→综合为"可持续性评分"。最终输出一个 SkillBench Score（0-100）+ 五维雷达图 + "同类排名"（比如"在 143 个代码审查 Skills 中排名第 7"）。定价：Free——每月评测 1 个 Skill，获得基础评分+五维雷达图。Maker——¥29/月，每月评测 5 个 Skill，获得完整报告+同类排名+修复建议（针对低分维度给出"如何提升质量"的具体建议）。Pro——¥99/月，每月评测 20 个 Skill+批量对比+API 接入+CI/CD 集成（每次 Skill 更新自动重新评测）+白标报告；② Skills 排行榜与发现平台（内容产品+获客引擎。SkillBench 维护公开的分类排行榜。分类体系：代码审查/安全扫描/测试生成/文档生成/项目管理/数据分析/设计审查/DevOps/API 集成/内容创作/研究分析/其他。每个分类展示 Top 20 Skills——排名依据 SkillBench Score+用户评分加权。每个 Skill 详情页展示：SkillBench Score（五维雷达图）、同类排名、用户评价、兼容平台列表、最近更新时间、"谁在用这个 Skill"（展示集成了该 Skill 的知名项目）。评论区允许用户提交"这个 Skill 的实际使用体验"——形成社区驱动的质量反馈循环。排行榜的 SEO 价值："Best code review skills for Claude Code 2026""Top 10 AI agent skills for
