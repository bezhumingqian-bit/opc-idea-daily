01 ToolMart——Agent 工具计量市场与账号托管层 · treg「OpenRouter for agent tools」：卡住 agent 的不是缺工具，是工具背后的合同
9 月 22 日，GitHub 趋势上 superdesigndev/treg（2,113 星，+197）用一句话重新定义一个缺口："OpenRouter，但给 agent 工具而不是模型"——一个 base URL + 一个 token，agent 就能调用 60+ 供应商的 3000+ 计量端点（外链数据、社媒趋势、联系人富化、广告、爬虫、图/视频生成），按次计费，无需逐个签约。它点破一个被忽略的真相：真正卡住 agent 的通常不是"缺工具"，而是"工具卡在合同/月费/企业审批后面"——Semrush $139/月、Crunchbase $99/月，或压根没有公开 API。与 Composio 的本质区别：这是计量市场，不是 OAuth 集成平台；账号由 treg 集中托管，密钥注入在服务端，调用方永远拿不到密钥。同向信号：同日 Product Hunt 顶部 Jev（typed decisions）、Superset Mobile（移动端编排 coding agent）、Arcjet（运行时安全）都在把"agent 能不能在真实生产里用起来"推成共识。核心洞察：当 agent 已经能规划、能下命令，它的上限不再靠推理，而靠它能"借到"哪些被合同和账号挡在门外的能力。
OPC 路径：做"ToolMart"——Agent 工具计量市场与账号托管层。定位：一人公司给 agent 接数据/工具时，最烦的不是找不到工具，而是每个工具都要单独注册、谈价、绑卡、过企业审批。缺的不是又一个工具目录，是"一个 token 用遍所有工具、按次付费、免签约"的计量市场。① 工具目录（核心产品。3000+ 计量端点按任务分类，agent 按"要什么"搜索而非按"哪家卖"）。② 计量计费（按次计费，一张账单，用量可审计）。③ 账号托管（服务端密钥注入，agent 拿结果不拿密钥，权限可回收）。定价：Free——按需单工具。Maker——¥29/月，30 次调用 + 常用目录。Pro——¥99/月，不限调用 + 账号托管 + 用量审计。冷启动：渠道 A——开源"ToolMart Core"计量网关。渠道 B——数据帖"卡住 agent 的不是缺工具，是工具背后的合同"。渠道 C——搭 treg 顺风车。Founding Member：Pro ¥49/月终身。

02 OfficeHarness——Agent 办公文档 headless 运行时 · univer「Office Harness for AI Agents」：让 agent 不开 Excel 也能算表格
9 月 22 日，dream-num/univer（15,214 星）冲上 GitHub TypeScript 日榜第一，做了一次很"反直觉"的重新定位：从"可嵌入的 Office SDK"改为"AI Agent 的 Office Harness"——同一套 headless 运行时跑在浏览器或 Node.js，让人和 agent 编辑同一份文件。关键架构判断：大多数"Office+AI"的做法是让 agent 去调已有应用的 API；univer 反过来，把表格公式引擎和画布渲染器变成可嵌入的无头组件，agent 能在服务端跑表格逻辑，而不用真的打开一份 Excel。同向信号：同日 GitHub 趋势里 docling（文档解析喂给 gen-AI 管线，+585）、diffusionstudio/editor（把视频剪辑表达成代码）、vercel/json-render（从 JSON 渲染动态 UI，+291）都在做同一件事——把"只有人能操作的格式"变成"agent 能直接计算的格式"。核心洞察：agent 处理办公三件套（表格/文档/PPT）长期卡在"要么开真应用、要么没有渲染引擎"；谁把办公的画布与公式引擎做成 agent 可借的 headless 运行时，谁就占了"算得动"的入口。
OPC 路径：做"OfficeHarness"——Agent 办公文档 headless 运行时。定位：一人公司让 agent 做报表、对账、合同、PPT 时，最头疼的是让 agent"算得动"Excel 公式、排得动文档版式。缺的不是又一个在线表格，是"agent 能无头调用的办公引擎"。① 无头公式引擎（核心产品。服务端跑表格公式/透视/图表，不开 Excel）。② 文档渲染层（docx/pptx 无头渲染成 agent 可读结构）。③ 人机同文件（同一份文件人和 agent 都能编辑，冲突可合并）。定价：Free——单文档。Maker——¥29/月，10 份文档 + 公式引擎。Pro——¥99/月，不限文档 + 渲染层 + 团队共享。冷启动：渠道 A——开源"OfficeHarness Core"无头引擎。渠道 B——数据帖"让 agent 不开 Excel 也能算表格"。渠道 C——搭 univer 登顶顺风车。Founding Member：Pro ¥49/月终身。

03 CutAgent——转写先行的 agent 视频剪辑层 · video-use：先转写后剪辑，比喂原始帧省 token 也更准
9 月 22 日，browser-use/video-use（25,702 星）让 Claude Code 直接剪视频：把原始素材丢进一个文件夹，聊天即得 final.mp4——删语气词和死气、调色、烧字幕、自动生成转场，全由 agent 完成。最有价值的是一处工程判断：LLM 从不着帧看视频，先读 ElevenLabs Scribe 的转写（词级时间戳、说话人分离、连笑声和掌声都有标签），只在需要核对某一刀时才拉一张"胶片条+波形"合成图。先转写、后剪辑，比把原始帧喂给模型省 token，也更精确。同向信号密集：OpenCut（CapCut 开源替代，+129）、autoclip（自动切片/高光生成，+395）、OpenCreator（视频/图/语音/数字人 agent 工作流，+263）——视频剪辑正成为"把耗时手工活交给 agent"的最大一块。核心洞察：剪辑真正的瓶颈不是"能不能剪"，是"理解时间轴"；把视频先变成文本，剪辑问题就退化成了文本问题。
OPC 路径：做"CutAgent"——转写先行的 agent 视频剪辑层。定位：一人公司做内容（口播、课程、播客、产品 demo）最烧时间的是剪辑；而大多数剪的是"删废话、对节拍、加字幕、调色"这类可规则化的活。缺的不是又一个剪辑软件，是"先转写、再按语义切"的 agent 剪辑层。① 转写先行（核心产品。素材先转成带时间戳的文本，语气词/重复/停顿标注）。② 语义剪辑（按"删哪句、留哪段"的文字指令精准下刀，自动对齐节拍）。③ 成片装配（字幕/转场/调色一键套模板，复用已有视频模型/工具链）。定价：Free——5 分钟素材。Maker——¥29/月，30 分钟 + 语义剪辑。Pro——¥99/月，不限时长 + 批量 + 团队共享。冷启动：渠道 A——开源"CutAgent Core"转写剪辑引擎。渠道 B——数据帖"先转写后剪辑，比喂原始帧省 token 也更准"。渠道 C——搭 video-use 25K 星顺风车。Founding Member：Pro ¥49/月终身。

本期钩子
9 月 23 日三条信号指向同一件事：当 agent 已经能规划、能下命令，它的上限不再靠"推理"，而靠它能"借到"多少被合同、格式和账号挡在门外的能力。信号一：treg——"卡住 agent 的不是缺工具，是工具背后的合同"，这就是 ToolMart（工具计量市场）。信号二：univer——"让 agent 不开 Excel 也能算表格"，这就是 OfficeHarness（办公无头运行时）。信号三：video-use——"先转写后剪辑，比喂原始帧省 token 也更准"，这就是 CutAgent（转写先行剪辑层）。共同主线：往期 Vol.042 讲"供给"，Vol.043 讲"可信"，Vol.044 讲"经营"，Vol.045 讲"接得通"（工具协议），这一期再往下一层——接得通之后，要"借得到"：工具（借账号）、办公（借引擎）、剪辑（借转写）。当推理不再是瓶颈，稀缺的是"把 agent 缺的那块能力，做成它能随时借到的基础设施"。
