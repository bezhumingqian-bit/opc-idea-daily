01 Agent 搜索基础设施 · AnySearch 登顶 PH #2，“Agent 的搜索框不是搜索框，是结构化信息管道”
昨日 Product Hunt #2 AnySearch（537票）打出标语"Real-time structured search trusted by agents and developers"——AI Agent 的好坏取决于它接收的信息质量，传统搜索框返回的原始 HTML 对 Agent 来说不可用。AnySearch 对搜索结果去重、过滤、结构化后返回给 Agent，Free to start。同日 PH #4 Octolens（390票）定位"Social listening for the agent era"——Agent 读不了 Reddit、Hacker News、播客和新闻，需要一个 API 让 Agent 能"听到"互联网上的所有提及。两个产品从不同角度揭示同一个缺口：Agent 的信息摄取层极原始。当 Claude Code、Codex、Cursor 成为主流开发工具后，Agent 需要的不再是搜索框，而是经过清洗和可信度评分的结构化信息流。这不是 SEO 2.0——这是 Agent 信息基础设施的空白层。
OPC 路径：做"AgentFeed"——面向 OPC 开发者的轻量信息流 API，curl 调用返回结构化 JSON。不做通用搜索引擎，专注三个 Agent 场景：① 竞品动态（自动监测竞品的产品更新/融资/负面舆情，每日摘要）；② 市场信号（追踪目标行业的 PH 新品/GitHub 新仓库/Reddit 热门帖/HN 讨论，按热度排序）；③ 品牌监测（产品名在各平台的提及频率和情感分析，自动标记负面信号）。技术栈：Serper.dev API + Reddit/HN RSS + PH API + Claude 做内容清洗和可信度评分。定价 Free 3个关键词，Pro $19/月 20个关键词，Business $79/月 100个+自定义信源。冷启动：免费工具"竞品雷达"——输入你的产品名和 3 个竞品名，自动生成一份最近 30 天的竞品动态报告 PDF，用于收集 email。

02 Agent 原生 Office 工具层 · OfficeCLI 9.7K⭐ + Neo $30M + Bloome，办公软件正在从“人用”变成“Agent 用”
7月8日 GitHub Trending 出现一个新品类信号：OfficeCLI（9.7K⭐，单日+802）自称"首个专为 AI 智能体构建的 Office 套件工具"——免费开源单二进制，无需安装 Office，Agent 直接读取、编辑和自动化 Word/Excel/PPT。同日腾讯 CubeSandbox（8.3K⭐）提供 Agent 沙箱环境，claude-video（5K⭐）让 Claude 能"看视频"。Industry 层同步共振：7月2日 Bhavin Turakhia 以 $30M 个人投资推出 Neo——自称"agent-native architecture"直接挑战微软 Office 和 Google Workspace，用户通过自然语言与持久 Agent 交互建文档/做报表/发邮件，而不是手动点击。Bloome 让人类和多个 Agent 在同一对话中协作。这三件事指向同一结论：2026 年办公工具的下一波不是"给 Office 加 AI 聊天框"，而是整个办公工具栈正在从"给人用的"变成"给 Agent 用的"——一个全新品类正在形成。
OPC 路径：做"AgentDesk"——面向 OPC 开发者的极简文件处理 API，不是给人用的办公软件，是给 Agent 用的。三个核心能力：① PDF→结构化 Markdown（含表格提取、图表 OCR、层级标题识别，专为 RAG 和 LLM 上下文优化）；② Excel 批量读写 API（Agent 读取数据→AI 分析→写回 Excel，支持公式保留和格式继承）；③ Word 模板填充（传入 JSON→生成排版精美的 Word 文档，含目录和页码）。技术栈：OfficeCLI 云端部署 + 微软 markitdown（161K⭐）做 PDF 解析 + LibreOffice headless 做格式转换。定价 $9/月 500次调用，$29/月 3000次，$99/月 无限+批量。冷启动：开源核心引擎放 GitHub，README 标题"Your AI agent deserves its own office suite. No Excel required."；在 r/SaaS 发技术帖"How we built a document API that Claude Code can actually use"。

03 AI 应用安全渗透测试 · T3MP3ST 爆发 + Strix 38K⭐ + 52K 人关心提示词泄露，AI App 上线前需要“安检”
7月7日 GitHub Trending 出现一条新安全工具链：T3MP3ST（2.5K⭐，本周爆发式增长）自称"自主红队平台和多 Agent 进攻性安全元框架"——让 AI Agent 自动模拟攻击者测试自身系统的安全性。Strix（38K⭐，7天+11K⭐）用多 Agent 编排做开源 AI 渗透测试。最具标志性的是 system_prompts_leaks（52.8K⭐，单日+1,704⭐）——一个 GitHub 仓库收录了 Anthropic Claude、OpenAI GPT、Google Gemini 等全部主流 AI 的系统提示词被泄露的内容，52K 人关注"AI 的底层指令是什么"。这三件事合在一起说明：2026 年每个 AI 应用上线前，都应该跑一遍安全检查——提示词有没有被注入的风险？敏感数据会不会从 AI 输出中泄露？但现有工具要么是给大企业用的（太贵太复杂），要么是开源的（需要安全工程师才能部署和解读结果）。
OPC 路径：做"PromptScan"——面向 indie maker 的轻量 AI 安全审计工具，三步生成一份安全报告。① Prompt 注入检测（自动模拟 50+ 种已知攻击手法测试你的 prompt 模板，标记可被越狱的风险点）；② 敏感数据暴露检测（扫描 AI 输出日志，标记意外包含的 API Key、用户 PII、内部系统逻辑等）；③ AI 供应链安全评分（分析你依赖的 LLM API/Skills/MCP 插件，交叉比对已知漏洞数据库，生成风险等级）。免费版：手动跑一次完整审计。Pro $29/月：自动每周审计 + GitHub CI 集成（每次 PR 自动跑安全扫描）+ PDF 审计报告。冷启动：做一个免费单页工具"Is your prompt leakable?"输入你的 prompt 模板，AI 扮演攻击者尝试提取敏感信息，成功提取后提示"你的 prompt 在 X 分钟内被攻破，这是修复建议"，用于收集 email。

04 隐私优先 AI 协作工具 · meetily 20.5K⭐ 登顶 + 本地 AI 趋势，“数据不出本地”从卖点变成护城河
7月8日 GitHub Trending 增速最快的项目之一是 meetily（20.5K⭐，单日+1,781⭐）——Rust 构建的隐私优先 AI 会议助手。核心卖点：Parakeet/Whisper 实时转录（速度快 4 倍）、说话人分离、Ollama 自动摘要、100% 本地处理无需云端，一句"Your data never leaves your machine"击中了最核心的焦虑。同期端侧推理生态加速：Cactus 提供移动端本地 LLM 框架、Meta ExecuTorch 在 Instagram/WhatsApp 服务数十亿用户、Ollama（160K⭐）成为本地推理的事实标准。这条线说明：AI 全面渗透工作的 2026 年，企业和一人公司都面临同一个问题——AI 很好用，但把客户数据、财务数据、商业机密发给云端 LLM 让人睡不着觉。"数据不出本地"正在从一小撮极客的癖好变成主流市场需求。但本地部署的门槛仍然很高：meetily 需要配置 Rust 环境、下载模型、调通音频设备——普通用户搞不定。
OPC 路径：做"LocalVault"——本地优先的 OPC 知识管理与协作桌面工具。不是造新模型，是基于 Ollama + Whisper + meetily 等开源组件做体验包装。三个场景：① 本地会议纪要（一键录音→本地转写→AI 摘要→自动生成待办，所有数据在本地 SQLite）；② 本地文档问答（拖入 PDF/Word/网页文件夹→本地向量索引→用 Ollama 做 RAG 问答，零文件上传）；③ 本地客户洞察（导入邮件导出/聊天记录→AI 提取待办事项/客户情绪/关键信息，生成客户周报）。定价：基础版免费（单机，2个项目空间），Pro $19/月（团队共享索引+自动备份到本地 NAS+邮件摘要发送），Enterprise $79/月（多设备同步+SSO+审计日志）。冷启动：在 Hacker News 发"We built an AI knowledge base that never sends your data to a server. Here's the architecture."附带技术架构图和隐私承诺；即刻发"不想把商业机密发给 OpenAI？这个本地 AI 工具帮你管所有文档和会议"。

05 Agent Skills 发现与评测平台 · 生态爆发到 72K⭐ 但缺 “npm for Skills”，碎片化是独立开发者的机会
7月第2周 GitHub Trending 的 Skills 生态数据：agent-skills（72K⭐，单日+1,311⭐）提供生产级工程技能集，mattpocock/skills（159K⭐）是 TypeScript 宗师的反氛围编程武器库，taste-skill（58.5K⭐）让 AI 输出避免无聊通用化，caveman（86K⭐）用极简表达削减 65% token，OpenWiki 自动为代码库编写 Agent 文档。Skills 生态以每周数万 star 的速度增长，但发现、选择和验证完全靠社交传播和 GitHub star 数——没有搜索、没有评测、没有兼容性检查、没有质量评分、没有"这个 Skill 适不适合我的项目"的基准测试。这就像 2012 年 npm 之前的 JavaScript 生态：碎片化、不可靠、靠口碑传播。更关键的是：Skills 的 GitHub star 数越来越不能反映实际质量——caveman 86K⭐ 因为"骚操作"出圈，但它在你的具体代码库上到底省了多少 token？没有人能量化回答。
OPC 路径：做"SkillHub"——Agent Skills 的发现与评测平台（GitHub + ProductHunt + npm 三合一体验）。不卖 Skills，不做托管，只做三件事：① 索引（自动抓取 GitHub 上所有 Skills 仓库，按 Agent 平台/功能分类/依赖/安装方式自动打标签，支持自然语言搜索"帮我找一个能压缩 Claude Code token 但不会影响代码质量的 Skill"）；② 评测（用户评分 + 客观 Benchmark Runner——用标准测试任务在不同代码库上跑同一个 Skill，输出 token 消耗/准确率/误报率对比）；③ 一键安装（生成标准化安装命令，支持 Claude Code/Codex/Cursor/OpenClaw 四种主流 Agent）。商业模式：免费搜索和浏览，Pro $9/月（Benchmark 数据+Skill 对比+版本更新提醒+新 Skill 上线通知），团队 $29/月（内部 Skill 私有库+Skill 审批流程+用量统计）。冷启动：先做一个 GitHub Action "SkillScore"——自动扫描 Skills 仓库结构并生成质量评分 badge 放在 README 里，分类标签+安装兼容性+依赖健康度三指标，做到病毒传播。
