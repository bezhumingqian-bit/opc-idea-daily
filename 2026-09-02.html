01 SignalPipeline——OPC 的公开购买信号转销售管线引擎 · BrandJet 登 PH #2，网上有人正在求购你卖的东西
8 月 31 日，Product Hunt 日榜 #2 被 BrandJet 拿下（274 票），标语 "Turn public buying signals into sales pipeline"（把公开购买信号变成销售管线）：它监听 X、Reddit、LinkedIn 和开放网络，捕捉那些"正在询问某企业能解决的问题"的人，把这些信号富化成线索，然后在一个平台里跑 outreach、统一收件箱、CRM 到签约的完整工作流，还带 MCP 支持让 AI Agent 直接消费这些信号。关键洞察：一个人没有销售团队，最痛的不是"没有线索"，是"网上明明有人正在求购我卖的东西，我却看不见"——购买意图散落在公开提问里（"求推荐一个能做 X 的工具"），而冷邮件和投广告已经越来越难触达（往期 AnswerRank 讲过"冷邮件已死、AI 推荐成新渠道"，SoloPipe 讲的是网站访客的入站转化）。BrandJet 证明"把公开购买信号翻译成销售管线"是真需求，但它面向有销售团队的公司，一个人用不起、也接不住一整套 CRM。这条是"公开社交平台 B2B 购买意图监听 + 一人销售管线"。
OPC 路径：做"SignalPipeline"——OPC 的公开购买信号转销售管线引擎。定位：不是"网站访客入站转化"的 SoloPipe，也不是"社群本地服务代客行动"的 WarmAct，是"公开社交平台 B2B 购买意图监听 + 一人销售管线"。① 购买信号监听核心（核心产品。监听 X/Reddit/LinkedIn/垂直社区里"求推荐/求工具/吐槽竞品"的公开信号，按"是不是你的目标客户、意图多强、离成交多远"打分排序）。② 线索富化与一人销售管线（把信号富化成线索卡——谁、问什么、预算暗示、竞品态度，进一个轻量 CRM，自动起草第一封 outreach，跟进节奏可视化，一个人也能跑完整销售流程）。③ AI Agent 原生消费（MCP 接入，让 Claude/Codex/企微里的 AI 助手直接读信号流、回答"今天谁最值得联系"，一个人不用天天刷社媒）。定价：Free——1 个关键词监听 + 信号流。Maker——¥29/月，10 个关键词 + 线索富化。Pro——¥99/月，不限关键词 + AI 起草 + MCP 接入。冷启动：渠道 A——开源"SignalPipeline Core"信号监听脚本（MIT）。渠道 B——数据帖"网上有人正在求购你的产品，你却还在写冷邮件"。渠道 C——搭 BrandJet 登榜顺风车。Founding Member：Pro ¥49/月终身。

02 ShipPlan——一人公司带护栏的 AI 全 SDLC 分步驱动 · Interactive Sessions 登 PH #3，12 个 agent 跑同一工单成本差 160 倍
8 月 31 日，Product Hunt 日榜 #3 被 Revolte 的 Interactive Sessions 拿下（272 票），标语 "Drive the full SDLC with AI agents, step by step"（让 AI agent 分步驱动完整软件开发生命周期）：用户引导 AI agent 从架构、代码、测试、预发布到部署一步步走完，另有 Autopilot 模式跑 Jira 工单，全程带计划审批、内联 diff、成本上限和审计轨迹。同期 DEV 社区把 "loop engineering" 捧成夏季热词：Anthropic 的 Boris Cherny 说 "I don't prompt Claude anymore. I have loops running that prompt Claude."；Manfred Steyer 让 12 个 AI agent 跑同一张工单，成本差 160 倍、速度差 19 倍，结论一针见血——"每一个系统性失败都追溯到工单没写清楚，loops 不修模糊的 spec，只会原样执行它"。关键洞察：一个人 vibe coding 最容易翻车的两处，一是没有"计划审批 + 成本上限 + 审计轨迹"，AI 一路狂奔把架构搞乱、账单跑飞；二是没人替你把需求写清楚，loop 一旦跑偏就批量产出垃圾。往期 LaunchQA（上线前质检）、ShipGrade（企业级交付分级）都不同，这条是"给一个人的完整 SDLC 分步驱动 + 护栏"。
OPC 路径：做"ShipPlan"——一人公司带护栏的 AI 全 SDLC 分步驱动。定位：不是"上线前质检"的 LaunchQA，也不是"企业级交付分级"的 ShipGrade，是"完整软件开发生命周期的分步驱动 + 护栏"。① 分步 SDLC 驱动（核心产品。把"架构→代码→测试→预发布→部署"拆成分步关卡，每一步 AI 出方案、你审批后进入下一步，中途可打断改方向，不再让 AI 从头一路黑跑到底）。② 成本上限与审计轨迹（每次运行设成本上限、记录每一步 diff 和决策，超支即停，跑完能回看"哪一步花了多少钱、改了什么"——这是 vibe coding 最缺的两样）。③ 需求澄清前置（开工前 AI 先审一遍需求/工单，把"没写清楚的地方"追问清楚再启动——呼应 Steyer 的发现：失败全因工单没说清）。定价：Free——1 个项目 + 分步驱动。Maker——¥29/月，3 个项目 + 成本上限。Pro——¥99/月，不限项目 + 审计轨迹 + 需求澄清。冷启动：渠道 A——开源"ShipPlan Core"SDLC 分步模板（MIT）。渠道 B——数据帖"12 个 agent 跑同一工单成本差 160 倍，因为工单没写清楚"。渠道 C——搭 Interactive Sessions 登榜顺风车。Founding Member：Pro ¥49/月终身。

03 AgentBill——Agent 工具的宿主内计费与变现层 · 1 万个 MCP 服务器只有 5% 在赚钱
The Agent Times 一份被反复引用的数据点破了 Agent 经济的尴尬：MCP 生态已有 10,000+ 活跃服务器、TypeScript/Python SDK 累计 9700 万次月安装，但只有不到 5% 的服务器产生任何收入——"MCP 经济是一个没有钱的经济"。ChatGPT App SDK 的 2026 现状更直白：尚不支持内购或数字商品，变现唯一被支持的路径是 link-out 回你自己的网站。Indie Hacker Ashifur Khan 的帖子是活样本：他用 5 个月把 HookLayer（跑在 ChatGPT/Claude 里的 MCP server）做到 1,500+ 用户、40+ 国家、收入 3 个月涨约 500%，但 MRR 只有 $232，他自己点破原因——"在 ChatGPT 里卖 MCP 工具比普通仪表盘难，用户不愿在一个已经付过费的工具里再付一次钱"。同期 DEV 上的 Tanso 用 MCP 做 entitlement/用量计费（"运行前一个 API 判断该不该跑、余额够不够"）。关键洞察：Agent 工具的变现断层——大家拼命发工具却收不到钱，缺的不是"再做一件工具"，是"给独立开发者的 Agent 工具分层计费/变现基础设施"。往期 AgentMart（把工具卖给 AI Agent 的市场撮合）、ComplianceAPI（全球收款合规）、CostAudit（AI 账单审计）都不同，这条是"Agent 工具本身的用量计费 + entitlement 门禁 + 宿主内定价"。
OPC 路径：做"AgentBill"——Agent 工具的宿主内计费与变现层。定位：不是"卖工具给 AI Agent"的 AgentMart，也不是"收款合规"的 ComplianceAPI，是"Agent 工具本身的用量计费 + entitlement 门禁 + 宿主内定价策略"。① 用量计费与 entitlement 门禁（核心产品。给 skill/插件/MCP 工具接上"运行前一个 API 判断该不该跑、余额够不够、在不在套餐内"的计费门禁，按调用量/用量收费，超支即停，不用自己写 Redis 计数器）。② 宿主内变现策略（破解"用户不愿在宿主内二次付费"——把 link-out、试用额度、按结果定价、宿主内升级卡片打包成可复制方案，帮独立开发者找到"在 ChatGPT/Claude 里怎么收费才不招人烦"的路径）。③ 免费转付费转化引擎（盯"谁重度用但没付费"，自动提示升级时机与话术，参考 HookLayer"1500 用户只 232 MRR"的教训，把免费重度用户筛出来）。定价：Free——1 个工具 + 基础计费。Maker——¥29/月，5 个工具 + entitlement。Pro——¥99/月，不限工具 + 转化引擎 + 宿主内定价方案。冷启动：渠道 A——开源"AgentBill Core"用量计费 SDK（MIT）。渠道 B——数据帖"1 万个 MCP 服务器只有 5% 在赚钱，你缺的不是工具是计费层"。渠道 C——搭 MCP 变现热帖顺风车。Founding Member：Pro ¥49/月终身。

本期钩子
9 月 2 日三条信号指向同一层判断：独立开发者已经从"能不能做出来"走到"能不能卖出去、交付稳、收得到钱"，而这三件事各有一道断桥。信号一：BrandJet 登 Product Hunt #2——"把公开购买信号变成销售管线"，网上明明有人正在求购你卖的东西，一个人却还在写没人回的冷邮件，这就是 SignalPipeline（公开购买信号转销售管线）。信号二：Interactive Sessions 登 PH #3——"让 AI agent 分步驱动完整 SDLC"，DEV 社区把 loop engineering 捧成热词，12 个 agent 跑同一工单成本差 160 倍、失败全因"工单没写清楚"，一个人却让 AI 无护栏地一路狂奔，这就是 ShipPlan（带护栏的 SDLC 分步驱动）。信号三：1 万个 MCP 服务器只有 5% 在赚钱——ChatGPT App 里没有内购只能 link-out，indie hacker 做到 1,500 用户 MRR 却只有 $232、用户不愿在已付费的宿主里二次付费，这就是 AgentBill（Agent 工具的宿主内计费变现层）。共同主线：一个人公司的下一波机会，不是"再做一件东西"，是"补齐从做出来到卖出去、交付稳、收得到钱的三段断桥"。谁补齐"卖得动 / 交付稳 / 收得到"三件套，谁就抓住 OPC 从"造工具"走向"经营闭环"的第九波机会。
