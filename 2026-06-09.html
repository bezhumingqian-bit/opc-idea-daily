01 本地商家 GEO 优化 · 中国蓝海 · 1-2 周可跑通 MVP
Generative Engine Optimization（GEO）是 2024-2026 年新崛起的细分赛道——专门帮本地商家优化"被 AI 推荐"的概率。类比 2010 年的 SEO 普及，但 AI 推荐引擎比 Google 更集中：豆包 / Kimi / DeepSeek / 文心一言 用什么 prompt 调数据、怎么排序，几乎没人讲清楚。中国 8000 万本地商家，99% 不知道 GEO 是什么。
MVP 路径：选 1 个城市（建议上海/深圳）→ 找 10 家餐饮/医美/教培商家 → 用 Claude/DeepSeek 帮他们改门店描述、菜单话术、FAQ → 2 周内展示"被 AI 推荐次数"前后对比 → 月费 ¥1000-3000/家起步。1 人 + 业余 5-10 小时/周即可。参考：北美 Yext、Uberall 已是独角兽。

02 垂直 AI Agent 代搭建 · 跨境电商 / 宠物医院 / 房产中介
不是写一个万能 Agent——而是把 Claude/DeepSeek 套到具体行业里。Marc Lou 用 6 个月做 ShipFast（shipfa.st）做出 9 万美元月收入；Pieter Levels 一个人做 nomadlist.com 估值 8 位数。关键不是"模型能力强"，而是"你对行业 know-how 深"。中国 30+ 行业，每个行业的"AI Agent 化"都还早。
起步：选 1 个你有资源的行业（比如你养宠物就做宠物医院 Agent）→ 跑 20 个客户访谈 → 列出"每天重复 3 次以上的事"→ 用 DeepSeek API + 简单 RAG 做 MVP → 一次性收费 ¥5000 + 月费 ¥499 起。客户粘性极高（换 Agent 的迁移成本 = 改 SOP）。
来源 · Marc Lou 公开复盘 / Pieter Levels nomadlist
03 CLAUDE.md / Skill 模板包销售 · 新品类 · 早进场即红利
2026 年出现的新品类：把"如何调教 Claude/Cursor 干某件事"打包成 Skill 模板卖。类比 2010 年的 SEO 关键词包——当年做"长尾关键词库"的个人站长大都月入 5-10 万。Karpathy 的 CLAUDE.md 仓库（166k+⭐）证明了：工程师愿意为"省自己 10 小时"付钱。海外 Gumroad / 国内小报童 都可卖。
起步 1 周：选 3-5 个高频场景（"为 SaaS 写 API 文档 CLAUDE.md"、"为电商生成详情页 Skill"、"为律师整理合同审查 Prompt"）→ 自己做一遍 → 写说明 + 用法 → 挂小报童定价 ¥39-99。零边际成本，做一次卖一年。
