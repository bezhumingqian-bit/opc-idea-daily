FocusFit——AI 输出注意力适配层 · i-have-adhd 35840 星登顶 GitHub，agent 输出信息够但读不下去

9 月 10 日 GitHub Trending 第一名是一个不起眼的 Python skill：ayghri/i-have-adhd，35,840 星，登顶原因不是模型更强，而是它解决了一个所有人都有痛点——agent 输出"信息是够的，只是读不下去"。README 写得很直白：先给下一步行动、清单最多 5 条、跳过开场铺垫、不要收尾客套。同一天 obra/superpowers（284K 星）、affaan-m/ECC（254K 星）也在做同一件事的另一个侧面：把"该怎么用 agent"的纪律固化成可复用资产。核心洞察：AI 让生成变得无限廉价后，稀缺的不是更多信息，而是"把信息收成让人读得下去、能立刻行动的形态"——往期 ReadHuman 管"语气去 AI 味"，这条管"信息结构与密度"，两个维度。

OPC机会→ 做"FocusFit"——AI 输出注意力适配层（不是去 AI 味的 ReadHuman，是"把 agent 冗长输出自动重塑成先结论、再行动、限条数的注意力友好格式"）。三层：(1) 输出重塑引擎（800 字输出自动压成"结论→3 步行动→关键风险"三段式，套你自己的信息密度偏好）；(2) 个性化注意力模板（限几条、要不要表格、结论放哪、要不要结尾，一次配置处处生效）；(3) 多 agent 统一出口（Claude Code/Codex/Cursor/Gemini 输出都过同一层重塑）。定价 Free/Maker ¥29/Pro ¥99。冷启动：开源 FocusFit Core 重塑管线+数据帖"你的 agent 信息是够的，只是读不下去"+搭 i-have-adhd 登顶顺风车。Founding Member Pro ¥49/月终身。

来源 · GitHub Trending 9/10（ayghri/i-have-adhd 35,840 星登顶）

ReproGate——Agent 修复前复现契约层 · DEV 爆款复盘：agent 修的 34 个 bug 里 11 个复发

9 月 10 日 DEV 上一篇《How I Taught My AI Coding Agent to Reproduce Bugs Before Fixing Them》刷了社区：审计一个月里 agent 修的 34 个 bug，11 个后来复发——1/3 是"治标不治本"。根因不是模型不会调试，而是"没先让 bug 复现就动手改"：LLM 是"合理性机器"，给它 bug 报告它总能找到说得通的理论去改，但没有复现就没有 ground truth，补丁编译过、旧测试也过（它们本来就抓不到这 bug），看着绿油油，缺陷还躺着。典型翻车：报告"CSV 导出丢最后一行"，agent 找到分页里一个 off-by-one 改了还写了测试，merge 后 bug 依旧——真实原因是 buffer 流没 flush。解法只有一条硬规则：没有 failing reproduction 就不许改非测试代码，落成三层——prompt contract + pre-commit hook + repro script 模板。核心洞察：往期 VerifyGate 是"验 AI 对代码的声称对不对"，这条是"修 bug 前先让 bug 复现"，事前复现契约 vs 事后验真，互补。

OPC机会→ 做"ReproGate"——Agent 修复前复现契约层（不是验真的 VerifyGate，是"把『先复现、再修复』这条纪律做成 agent 绕不过去的护栏"）。三层：(1) 复现契约钩子（bug 分支上，agent 改任何非测试代码前必须先有 failing repro 落库，否则拦截）；(2) 复现模板库（failing test/repro script 模板一键生成，测不出就给"3 次尝试后停下来报告"的体面退出）；(3) 复发追踪（记录每个 bug 的复现→修复→验证闭环，一个月后自动回查"治好又复发"的）。定价 Free/Maker ¥29/Pro ¥99。冷启动：开源 ReproGate Core 复现钩子+数据帖"你 agent 修的 bug，1/3 会复发"+搭 DEV 爆款复盘顺风车。Founding Member Pro ¥49/月终身。

FabForge——AI 制造设计层 · text-to-cad + pascalorg 同榜，agent 从写代码画图延伸到造实物

9 月 10 日 GitHub Trending 上两个"造东西"的项目同时上榜：earthtojake/text-to-cad（15,222 星），一套 Python agent skills for CAD/CAE/CAM——把自然语言或草图转成可制造的 CAD 规格，再对接仿真（CAE）和加工（CAM）；pascalorg/editor（23,144 星），开源 3D 架构编辑器，带本地 CLI + MCP 工具。共同指向一件事：agent 的能力边界正在从"写代码、画 2D 图"延伸到"造实物"——CAD（设计）、CAE（仿真）、CAM（加工）这条制造链，过去要专业工程师 + 昂贵软件，现在开始被 AI 拉平。核心洞察：当 AI 让写方案、画图、写代码都免费，稀缺继续往"离物理世界更近"的一端迁移——谁能让一人公司把产品想法直接变成"能交给工厂或 3D 打印的实物"，谁就抓住 AI 造物下半场。

OPC机会→ 做"FabForge"——AI 制造设计层（不是 CAD 软件本身，是"把一人公司/独立创客的想法转成能直接交给工厂或 3D 打印的可制造规格"）。三层：(1) 想法→可制造规格（自然语言描述产品→自动生成可 3D 打印/可加工的 CAD 规格 + BOM 物料清单）；(2) 可制造性体检（自动检查壁厚、悬空、公差、材料是否可行，出图前先过"能不能造出来"）；(3) 工厂对接（把规格转成工厂能直接报价的格式，3D 打印/CNC/注塑各出各的工艺单）。定价 Free/Maker ¥29/Pro ¥99。冷启动：开源 FabForge Core 规格生成管线+数据帖"你的 AI 能写代码画图，但它能造出实物吗"+搭 text-to-cad/pascalorg 顺风车。Founding Member Pro ¥49/月终身。

来源 · GitHub Trending 9/10（earthtojake/text-to-cad 15,222 星；pascalorg/editor 23,144 星）

本期钩子

9 月 11 日三条信号指向同一个词：收口。当 AI 让"生成"变得无限廉价，真正的活儿在三件"收口"——把输出收成读得下去的、把修复收成靠得住的、把想法收成能造出实物的。i-have-adhd 35840 星登顶——"你的 agent 信息是够的，只是读不下去"，→FocusFit（AI 输出注意力适配层）。DEV 爆款复盘——"你 agent 修的 bug，1/3 会复发"，因为没先复现就动手，→ReproGate（Agent 修复前复现契约层）。text-to-cad + pascalorg 同榜——"你的 AI 能写代码画图，但它能造出实物吗"，→FabForge（AI 制造设计层）。共同主线：上一期讲"设计"（在把活儿交给 AI 之前先把图、资产、任务塑形好），这一期再往下一层讲"收口"——AI 生成了一大堆，最后能不能变成"读得下去、靠得住、摸得着"的交付物，才决定它是玩具还是生产力。谁先帮一人公司把 AI 的产出收成真正的成品，谁就抓住 OPC 从"疯狂生成"走向"稳稳交付"的下半场。
