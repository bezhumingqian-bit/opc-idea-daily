ResearchTree——AI 研究可复现层 · OpenResearch 3,343 星登顶，AI 干活的记忆存在一个最容易丢的地方：聊天窗口

9 月 16 日 alphaXiv 团队的 OpenResearch（3,343 星，+531 单日，GitHub 日榜第一）把编码 agent 改造成研究 agent：把 Claude Code/Codex/OpenCode/Cursor 搬进本地研究工作台，让 agent 从"聊天框里的助手"变成"实验记录本旁的研究员"。核心是一个 git-native 的"实验树"——从 baseline 起栈式叠加变体，每个研究方向独立 agent 会话 + 独立 git worktree；每次运行都 immutable 存档当次代码快照，日志/diff/结果/产物全拴在产生它们的 commit 上。三个月后查"好结果怎么跑出来的"，翻仓库不是聊天记录。本地优先：项目/会话/实验/日志全存本机，接 LM Studio/Ollama 零 API 开销，算力可本地/SSH/云任意路由，账本总在自己机器上。核心洞察：AI 自动化研究的竞争，正从"谁跑得完"转向"谁的结果可信"。

OPC机会→ 做"ResearchTree"——AI 研究可复现层（一人公司用 agent 做调研/竞品/内容/增长实验时，缺的是"结果可复现可追溯可审计"）。三层：(1) 实验树工作台（baseline→变体栈式叠加，每个方向独立 worktree）；(2) 可复现档案（每次运行 immutable 存档到 commit，日志/结果/产物绑定代码快照）；(3) 多算力路由（本地/远程 GPU/云聚合，账本数据留本机）。定价 Free/Maker ¥29/Pro ¥99。冷启动：开源 ResearchTree Core 实验树引擎+数据帖"AI 干活的记忆存在一个最容易丢的地方"+搭 OpenResearch 登顶顺风车。Founding Member Pro ¥49/月终身。

来源 · GitHub alphaXiv/OpenResearch 3,343 星（9/16 日榜第一；git-native 实验树 / immutable 存档 / 本地优先）

DeterministicReview——确定性审查管线 · open-code-review 2,756 日增空降榜首，审查错一次就伤人信任，把不能出错的环节焊死

9 月 16 日阿里开源的 open-code-review（28,527 星，+2,756 空降榜首，Apache-2.0）给出清醒架构判断：审查的正确解法不是"更聪明的模型"，而是"确定性工程流水线 + LLM Agent 混合"。它把审查拆两半——文件筛选/规则匹配/评论定位这些"不能出错"的环节用工程逻辑硬约束（确定性、可复现、零幻觉），模型只做动态判断和上下文检索。README 硬数据：同样模型下，精度更高、token 只用约九分之一。内置 NPE/线程安全/XSS/SQLi 检查，支持 Go 自定义规则，集成 Claude Code/Codex/Cursor/OpenCode。反向信号（DailyDawn）：HN 507 分热帖曝光专有 AI 工具的代码安全风险，开发者开始担心把敏感代码交给黑盒工具。核心洞察：审查/审校/核对这类"错一次就伤人信任"的场景，架构原则是确定性为主、智能为辅——LLM 不是越多越好。

OPC机会→ 做"DeterministicReview"——确定性审查管线（一人公司让 agent 做代码审查/内容审校/财务核对/合同体检，最怕模型悄悄出错还看不出来）。三层：(1) 确定性规则引擎（文件筛选/规则匹配/定位标注等"不能错"的环节硬约束，零幻觉）；(2) 混合审查管线（确定性+LLM 拼接，模型只做动态判断，token 省九成）；(3) 多场景审查模板（代码审查/内容审校/财务核对/合同体检各出规则+模型组合）。定价 Free/Maker ¥29/Pro ¥99。冷启动：开源 DeterministicReview Core 规则引擎+数据帖"审查错一次就伤人信任"+搭 open-code-review 登顶顺风车。Founding Member Pro ¥49/月终身。

来源 · GitHub alibaba/open-code-review 28,527 星（9/16 日榜第一 +2,756；确定性+LLM 混合 token 省九成）

VoiceIntent——语音表达智能层 · Voiskey 480 票冲上 Product Hunt #2，AI 不该重写你是谁，语音输入的瓶颈从听写转向表达

9 月 16 日 Voiskey 以首日 480+ upvotes 冲上 Product Hunt 产品日榜第二名，打出的定位是"Expression Intelligence"（表达智能）而不是又一个语音转文字工具。"Say it rough. Send it right."——过去语音输入拼"听写准不准"，Voiskey 拼"懂不懂你想说什么"：先理解真实意图，再把粗糙口语按场景重写成恰当措辞。同样一句报喜，IM 里是"Quick bit of good news 🎉"，邮件里是"Sharing a quick update... 请抽空查看"，对外文档换正式语气——风格/语气/称呼全自动适配，同时保留个人词典和写作习惯，而不是改成别人的模板。护城河在隐私：音频和转录默认只存本机，零服务器留存，端到端加密，SOC 2 Type II + ISO 27001。同期语音赛道爆发（AGI Hunt）：Palabra.ai 同传 <1s，Typeless 免费额度从 8K 砍到 2K 词，Phonic 600ms 响应领跑。核心洞察：语音输入竞争正从"转录准确率"翻页，进入"表达智能 + 本机隐私"新战场。

OPC机会→ 做"VoiceIntent"——语音表达智能层（一人公司做内容/客服/销售/外贸/社群时，大量时间花在"把随口说的话改成得体文字"）。三层：(1) 意图理解（把 rough speech 转结构化意图——报喜/求助/说服/澄清）；(2) 分场景表达（IM/邮件/文档/对外文案不同语气自动适配，保留个人词典与风格）；(3) 本机隐私引擎（音频与转录零服务器留存、端到端加密）。定价 Free/Maker ¥29/Pro ¥99。冷启动：开源 VoiceIntent Core 意图理解管线+数据帖"AI 不该重写你是谁"+搭 Voiskey PH #2 顺风车。Founding Member Pro ¥49/月终身。

来源 · Product Hunt Voiskey 首日 480+ upvotes（#2；Expression Intelligence + 零服务器留存 SOC2/ISO27001）
