IDEA 02 垂直 Agent

垂直 AI Agent 代搭建服务（中国版）

基于扣子、Dify、Coze 等低代码平台，为跨境电商、宠物医院、房产中介等垂直行业搭建定制 Agent，按"搭建费 + 月费"收费。

痛点

大量中小企业主听说过 AI 但不会用、不会搭；通用客服/销售 Agent 满足不了行业属性（宠物医院要懂疫苗提醒）；自研成本太高，外包开发公司报价 5-10 万起步。

三、2026 年 OPC 的 5 条趋势暗线

  • Agent 编排是新的 SaaS：垂直 SaaS → AI Wrapper → Agent 编排平台，三代进化方向已清晰。
  • "卖结果"取代"卖工具"：用户付费越来越不愿意学工具，愿意为"最终交付物"（截图、PDF、文章、音乐）付钱。
  • Niche 比规模重要 10 倍：通用 CRM 输给垂直 CRM，通用 SEO 输给垂直 GEO，通用 newsletter 输给 niche newsletter。
  • 开源 freemium 是新 GTM：先做开源产品 → 自部署免费 → 托管增值，比纯闭源 SaaS 获客快 2-3 倍。
  • Boilerplate 共享是 Marc Lou 模式的护城河：不是某个产品牛，是整个产品栈共用同一代码库带来的边际成本优势。

四、风险提示

  • 数据真实性：所有营收数字均来自二手报道，未经独立审计。决策前请用一手来源二次核实。
  • 门槛被低估：micro-SaaS 中位数 $500/月，30% 跑不到 $1K MRR，不要只看头部故事。
  • AI Wrapper 同质化：GPT-4 / Claude / Gemini 包装类产品高度同质化，垂直 + 留存机制是唯一护城河。
  • 推理成本风险：Agent 类产品（Polsia 模式）对 token 消耗敏感，规模上去后毛利率会被压缩。
  • 合规风险：医疗（Medvi）、金融（FinceptTerminal）等 vertical 在中国需要资质，海外有 SEC 合规。
